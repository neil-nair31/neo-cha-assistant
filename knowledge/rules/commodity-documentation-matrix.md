# Documentation matrix by commodity type (starting checklist)

Always confirm with Neo CHA — PGA rules change via notifications.

## General (all)
Invoice, packing list, BL/AWB, IEC, GSTIN, PO/contract ref

## Steel / metals
Mill test certificate, weight list, heat numbers where applicable, anti-dumping awareness for specific origins/grades

## Chemicals
SDS/MSDS, UN DG declaration if hazardous, import licence if restricted

## Cashew / agro
Phytosanitary, fumigation if destination requires, moisture/grade specs, FSSAI if food-grade processing

## Marine (shrimp/prawns)
EIC/EIA norms historically relevant for EU/US — verify current export market rules with Neo

## Textiles
Composition labels, value declaration, scheme certificates if claiming benefits

## Automobiles / LCV
Chassis/engine numbers, homologation where required, dealer invoices

## Sanitaryware
Fragile packing declaration, damage survey clause awareness

## Project / ODC cargo
Route survey, axle load permits, lifting plans, insurance

## Assistant rule
Present as checklist only; Neo confirms final list after reviewing commercial invoice description.
