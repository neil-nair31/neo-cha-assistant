# Documentation Checklists (General)

**Cite as:** Standard EXIM documentation practice (educational). Final checklist is shipment-specific.

## Core commercial set
- Commercial invoice (seller, buyer, description, HS if available, currency, Incoterms, payment terms)
- Packing list (weights, dimensions, package count, marks & numbers)
- Transport document (BL / Sea Waybill / AWB / consignment note)
- Purchase order / contract reference

## India import extras (when applicable)
- IEC + GSTIN of importer
- COO / Form for preferential claims
- Product registration / BIS / FSSAI / CDSCO / PQ permits
- Insurance certificate (CIF/CIP)
- Technical literature for classification support

## India export extras (when applicable)
- Shipping bill supporting docs
- LUT / bond / drawback / RoDTEP declarations as applicable
- Inspection / quality certificates
- Phytosanitary for agri
- Bank / AD code details

## Neo onboarding docs (from public KYC page)
- PAN, GST certificate, IEC copy
- Utility bill (address proof)
- Directors / authorized signatory details
- Bank account + IFSC

## Assistant behaviour
If user asks “what do I need?”, give this checklist as a starting point and offer Neo team review — never claim it’s exhaustive for every HS code.
