# HS / tariff classification (educational)

**Cite as:** Harmonized System / Indian Customs Tariff practice (general).

## What is HS code?
- International nomenclature for goods (Chapters 1–99)
- India uses HS at 8-digit level in Customs Tariff
- **Wrong classification changes duty, exemptions, and PGA triggers**

## Who is responsible?
- Importer/exporter remains responsible under self-assessment
- CHA assists with classification support using documents and precedents
- Final classification for assessment may be confirmed with Customs

## What helps classification?
- Technical description, material composition, function, end-use
- Brochures, MSDS (chemicals), drawings (machinery)
- Similar past entries (not blindly copied)

## Assistant must NOT
- State "your HS is XXXXXXXX" as fact without Neo specialist review
- State duty % tied to a guessed HS

## Route to Neo when user asks "what is the HS for my product?"
Collect: product description, material, use, photo/spec sheet if available → Neo classification desk.
