# ICEGATE & port operations (educational)

**Cite as:** ICEGATE public FAQs / Indian Customs electronic filing practice.

## ICEGATE
- National customs electronic gateway for trade filing
- Bills of Entry, Shipping Bills, IGM/EGM and status tracking (for registered users)
- Trade portal includes dashboards, notifications, and help resources

## Typical port actors (India)
- **CHA / customs broker** — documentation & clearance liaison
- **Shipping line / agent** — vessel, DO, freight
- **CFS / ICD** — container stuffing/de-stuffing, storage
- **Custodian / terminal** — gate in/out
- **PGA** — food, plant, animal, drug, BIS, etc.

## Cochin (Kochi) context
- Willingdon Island HQ — Neo's primary CHA base
- Major gateway for Kerala industry, cashew, marine products, project cargo

## Chennai context
- Egmore operations office for Chennai corridor documentation support

## Container lifecycle (simplified)
Arrival → IGM → filing → assessment → examination (if any) → duty → OOC → DO → gate out → inland
