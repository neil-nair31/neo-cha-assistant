# Exposable SOPs (Public Educational Only)

> These explain **how customs clearance generally flows** in India for education.  
> They are **not** Neo internal SOPs, **not** legal advice, and **not** a guarantee of process or timing for any shipment.

## Import clearance — high-level flow
1. **Pre-arrival planning** — Importer/CHA review invoice, packing list, BL, COO, licences, PGA requirements; confirm IEC/GSTIN; assess likely HS family (classification finalized by importer with CHA support).
2. **IGM / arrival** — Vessel files Import General Manifest; container lands / available for clearance as per port rules.
3. **Bill of Entry filing** — Filing on ICEGATE (or as applicable) with supporting docs; self-assessment under customs self-assessment regime.
4. **Duty calculation & payment** — Assessable value (transaction value + additions per valuation rules), BCD, AIDC/SWS as applicable, IGST, ADD/CVD if any. **Exact rates need verified classification + live notifications.**
5. **Risk / RMS** — Facilitation vs examination selection.
6. **Examination / PGA** — Physical / scanning / sampling; NOCs from Food, Drug, Plant Quarantine, Animal Quarantine, BIS, etc. when triggered.
7. **Out of Charge (OOC)** — Customs releases goods for delivery after compliance.
8. **Delivery order / gate-out** — Shipping line DO, CFS/ICD/port gate passes, inland transport / warehouse as contracted.

## Export clearance — high-level flow
1. **Booking & stuffing** — Factory/CFS stuffing; seal; packing list accuracy.
2. **Shipping Bill** — Filed with invoices, packing list, schemes (Drawback/RoDTEP/Advance Authorization etc.) as applicable.
3. **Let Export Order (LEO)** — After assessment/examination as selected.
4. **Gate-in & loading** — Container to terminal; EGM / sailing.
5. **Export promotion / GST** — Post-shipment compliance as per exporter’s obligations.

## Common delay causes (educational)
- Incomplete or mismatched documents (HS, weight, description, COO)
- Missing PGA licences / labels
- Valuation queries / related-party issues
- Free-time / detention / demurrage if DO or transport delayed
- Weather / port congestion / line cut-offs
